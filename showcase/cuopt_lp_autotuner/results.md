## Key Policy Discoveries

The evolved policy found these optimizations:

1. **Disabled presolve** (`presolve: false`)
   - For the LP types in our corpus (transportation, capacity planning, etc.), presolve overhead exceeds benefits
   - This is instance-dependent - larger/harder problems may benefit from presolve

2. **Geometric scaling** (`scaling_method: "geometric"`)
   - Helps numerical conditioning without explicit row/column scaling transforms

3. **Reduced max iterations** (`max_iterations: 8657`)
   - Most problems converge well before the default 10000 limit
   - Reduces overhead from iteration checks

## Fitness Function Details

The fitness function combines:
- **Throughput score**: `(throughput / baseline - 1) × 100`
- **Latency score**: `(1 - p95 / baseline_p95) × 50`
- **Penalties**: Failure rate excess, correctness violations

Hard constraint: p95 regression must be ≤2% vs baseline.

1. **Enable transforms**: The current champion doesn't use row/column scaling transforms. These may help on larger, numerically challenging problems.

2. **Feature-conditional rules**: Evolve policies that select different settings based on LP features (size, density, numerical range).

4. **More generations**: With more evolution time, better policies are likely discoverable.

5. **cuOpt integration**: Replace the scipy fallback with real cuOpt to measure true GPU performance.
